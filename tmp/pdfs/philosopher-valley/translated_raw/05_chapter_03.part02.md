# 第三章：这家肩负怨气的硅谷初创公司

[[P021]] 不过，尽管卡普加入帕兰提尔时连一行代码都写不了，但指导公司软件工程师的思维方式对他而言并非完全陌生。数据科学中的一个关键概念是本体论，宽泛地定义，就是信息如何被组织和构建。这种映射功能对于在彼此分散的信息之间建立有意义的联系至关重要。本体论是科技界从哲学中挪用来的术语。在哲学的世界里，本体论是形而上学的一个分支，探讨存在的本质，并通过建立事物的类别（人、地点、物体）来描述现实。对卡普来说，理解本体论在数据科学中的应用并不算太大的跨越——事实上，他后来会说，帕兰提尔的软件本质上是一个哲学系统。在他及其同事看来，软件中的关键要素是其“动态本体论”，它使用户能够构建自身运营活动的“数字孪生”，并可持续更新和扩充，以映照组织的演变。

[[P022]] 虽然卡普或许无法讨论 Java 和 Python 等编程语言的细枝末节，但在某些方面，他是这样一家注定会引发怀疑的公司的理想首席执行官。他似乎真心热衷于保护隐私，并且能够以一种在科技圈罕见的流畅程度谈论公民自由相关议题。他出身学术界而非军方或情报界，这一点很有帮助——由一位受过训练的哲学家掌舵，表明帕兰提尔认真对待其工作所引发的伦理与道德忧虑。卡普自称左派，这同样有所助益；尤其当蒂尔开始进一步右倾时，他的政治倾向会成为帕兰提尔的一种盾牌。

[[P023]] 蒂尔、科恩、朗斯代尔和盖廷斯是在旧金山 Clarium 的办公室里创办帕兰提尔的。但公司很快需要更大的空间，于是迁至帕洛阿尔托桑德希尔路 3000 号。蒂尔正是在那里创办了 Confinity。起初，卡普并非每天都在办公室；他住在旧金山，每周会有几次前往帕洛阿尔托。由于不会开车，他雇了一辆车接送自己往返。早期的卡普对同事而言颇为神秘。有人半开玩笑地猜测，他的德国博士学位只是掩护，而他其实是一名间谍，可能为摩萨德效力。（多年后，卡普聘用了一名前以色列情报官员，充当某种意义上的他的掮客。）“我们不知道该怎么看待他，”2005 年加入帕兰提尔的软件工程师鲍勃·麦格鲁回忆道。他将其形容为一种“阻抗失配”，一种巧妙的说法，意思是他们不在同一个频道上。为了帮助卡普理解如今向他汇报的那些人，麦格鲁和其他几人送给他一本雷·库兹韦尔 2005 年出版的《奇点临近》，这本书迅速在硅谷获得了经典地位。它讲的是人工智能；计算机科学家兼未来学家库兹韦尔预言，奇点——即计算机超越人类智能的时刻——将在 2045 年到来。（后来，帕兰提尔的新员工会获发几本书阅读，其中包括劳伦斯·赖特关于奥萨马·本·拉登、基地组织以及导致“9·11”情报失误的《末日之塔》；还有《即兴》，一本表面上讲即兴戏剧、却作为创造力指南而拥有狂热追随者的书。）

[[P024]] 卡普平易近人、风趣好玩（当时和现在一样，他喜欢向同事大讲德国女性及她们对自己的吸引），但与他交谈可能颇为困难。他以非线性的方式抛出想法和观察，有时令同事摸不着头脑。“我不认为会有人说他很容易交谈，”布赖恩·辛普夫说；他于 2007 年受聘于帕兰提尔，最终成为工程总监。帕兰提尔设计主管约书亚·戈登伯格回忆，与卡普的讨论“没有结构”，有时似乎“有点不连贯”。卡普主持全员会议后，员工们会聚在一起，试图弄明白自己听到了什么。“我们会复盘，看有没有人能从卡普混乱的说话方式里辨识出信号，”一名前员工说。但他说，所有人都认可卡普拥有一种“疯狂的魅力”，而且极其聪明。

[[P025]] 同事们也惊讶于——而且颇感不安于——他让人接受自己看法、照自己意愿行事的能力。卡普坚持一种不受拘束的讨论文化，鼓励员工以绝对坦率的方式表达自己。“亚历克斯的态度是，你应该能让首席执行官也滚蛋，”另一位早期受聘的软件工程师阿基·贾恩说。“我们对任何事情都可以公开地反对和辩论，”辛普夫回忆道。即便如此，同事们仍感觉卡普仿佛几乎能够钻进人们的脑海，把自己的想法植入其中。一些帕兰提尔员工开始称他为“查尔斯·泽维尔”，也就是 X 战警中的 X 教授——那个拥有心灵感应能力的角色。

[[P026]] 从一开始，卡普就说帕兰提尔的使命是捍卫西方和自由民主。公司是“9·11”的产物，也是卡普悲观世界观的产物。甚至在“9·11”之前，卡普就怀疑冷战结束是否真的开启了一个不可逆转的和平与繁荣时代；针对美国的恐怖袭击表明，这是一种危险的幻觉，仍有很多人意图伤害我们。卡普和同事们并不认同帕兰提尔创立时盛行的科技乐观主义——即网络世界能够以某种方式让现实世界变得更美好、更幸福的观点。帕兰提尔毫无乌托邦色彩；如果说有什么不同，那就是公司建立在我们正面对黯淡未来的确信之上。帕兰提尔的电梯推介是：它的技术或许能够让末日般的事件少发生一些。

[[P027]] 帕兰提尔与其他科技初创公司不同之处还在于，它拒绝硅谷盛行的“快速失败，频繁失败”信条——即失败并不可怕，只是为未来成功奠定基础的一次挫折。卡普因为年龄相对较大，并不觉得自己拥有充裕的时间；他已三十多岁，而失败对他的代价将远高于一个刚从斯坦福毕业的二十二岁年轻人。此外，卡普不是技术人员——如果帕兰提尔倒闭，他并不能顺理成章地转去另一家初创公司。从他的角度看，失败根本不是一个选项，也不是什么应当拥抱的东西。卡普不认同贝克特式“下次失败得更好”的精神，因为并不能保证会有下一次；而他所感受到的紧迫感渗透到了帕兰提尔的各个层级。

[[P028]] 这并不是说帕兰提尔是一个充满生存主义者的阴郁工作场所（尽管多年后，卡普会把帕兰提尔称为“一家末日准备者公司”）。早期，它看起来和其他科技初创公司没什么不同：办公室里满是热情洋溢、有些书呆子气的年轻男性（这是一种高度男性化的文化，并且延续至今）。尽管没有高空滑索，帕兰提尔人也确实会放松玩乐；2016 年，一名前员工起诉帕兰提尔，称自己在一场喧闹的啤酒乒乓球游戏中受伤（案件庭外和解）。但人们有一种感觉：帕兰提尔服务的目标比其他初创公司更崇高——它在做重要的事。阿基·贾恩回忆，和他同届的斯坦福计算机科学专业学生中，最聪明的三个人最终参与了谷歌的“聪明屁股”项目——这是公司内部对其机器学习广告定向项目的昵称（该项目根据谷歌用户的搜索向其投放广告）。贾恩并非在作价值评判或暗示什么——他只是知道，自己更愿意从事看起来更具重大意义的工作。

[[P029]] 帕兰提尔总部设在硅谷，但在卡普和同事们心中，它从来不真正属于硅谷。卡普尤其蔑视谷歌和 Facebook。他很早便意识到，收集和出售个人数据是它们业务的核心，而他认为这些在伦理上可疑的商业模式可能伤害帕兰提尔；如果有一天大数据遭到反弹，人们未必会认识到，帕兰提尔的运营方式与谷歌和 Facebook 在根本上不同（帕兰提尔不收集、存储或出售数据）。后来，卡普不太愿意从这两家公司招聘人员。虽也有例外，但总体而言，他认为谷歌和 Facebook 的员工，无论多么有才华，都已内化了一种掠夺性的数据观念，这与帕兰提尔格格不入。

[[P030]] 卡普尤其憎恶 Facebook。作为搜索引擎，谷歌提供了正当的价值；在他看来，Facebook 毫无价值，是轻浮而具有破坏性的东西——用他的话说，“一种致癌物”。帕兰提尔和 Facebook 大约在同一时期成立，尽管两者不是竞争对手，但 Facebook 在某种程度上成了帕兰提尔用以界定自身的对照对象。蒂尔既是 Facebook 的重要投资者，又在其董事会任职，这表明其中或许也存在某种手足竞争。此外，两家公司似乎总是彼此相映。它们一度都将总部设在帕洛阿尔托同一个办公园区；而帕兰提尔后来在帕洛阿尔托扩张时，接管了一栋此前由 Facebook 使用的建筑。（Facebook 在那里办公的地点之所以出名，是因为墙壁由一名当地涂鸦艺术家绘制，而他获得的报酬是 Facebook 股票；2012 年公司上市时，他持有的股票价值约 2 亿美元。帕兰提尔搬入后，把墙壁重新粉刷覆盖了。）多年后，Facebook 和帕兰提尔都将卷入剑桥分析丑闻。

[[P031]] 帕兰提尔早期的大部分招聘都靠口耳相传。2005 年，包括鲍勃·麦格鲁在内的一群斯坦福校友住在洛斯阿尔托斯山的一栋房子里；这栋房子以一个深受计算机科学专业学生欢迎的兄弟会命名，非正式地被称为“南部 Phi Psi”。一天晚上，阿基·贾恩在那里参加派对，并与麦格鲁长谈。麦格鲁鼓励他申请帕兰提尔的职位。不久之后，贾恩加入公司。斯坦福距离近且拥有大量工程人才，显然是帕兰提尔招聘新人的理想地点。朗斯代尔和科恩在计算机科学楼里张贴海报，上面写着：“你一半像比尔·盖茨，一半像詹姆斯·邦德吗？帕兰提尔就是你的归宿。”无论是个人关系、这些传单，还是两者兼有，许多斯坦福毕业生最终进入了帕兰提尔。

[[P032]] 帕兰提尔迁往帕洛阿尔托后，蒂尔很少到办公室（他偶尔造访时，人们会为他摆上一碗开心果——他爱吃这个）。但他确实帮忙招聘。2004 年，他试图说服一位名叫加里·谭的年轻工程师离开微软、加入帕兰提尔。他把谭飞到旧金山，带他去 Frisson 吃晚餐，并鼓励他为自己的新创公司工作。蒂尔承诺，如果谭加入，将给他一大笔股权。有一次，蒂尔问谭在微软的薪水是多少。谭说是 72,000 美元，于是蒂尔拿出支票簿，按这个金额给他开了一张支票，作为额外诱因。但谭拒绝了这笔钱和这份邀约——他想留在微软。许多年后，谭在一支名为《我犯下的 2 亿美元错误》的短视频中讲述了这个故事。最妙的是，在他拒绝蒂尔邀约不久后，他却接受了帕兰提尔的一份工作，成为公司的第十位员工。他甚至设计了帕兰提尔的标志，之后成为一名成功的风险投资家，并担任孵化初创公司的 Y Combinator 的首席执行官。但如果他更早加入帕兰提尔，他本可以多拥有数亿美元财富。

[[P033]] 要在帕兰提尔获得职位，你必须表现出对公司使命的热情——如果候选人对运用技术杀死恐怖分子并不狂热，或者对与美国政府合作显得畏缩，他或她就不可能被录用。另一个一票否决项是任何一夜暴富野心的迹象。得益于 20 世纪 90 年代末的互联网热潮，硅谷被视为一个能在相对短的时间内获得惊人财富的地方：你会在一家初创公司辛苦几年，薪酬部分或大部分以股权形式支付；公司上市后，你便会套现获利。但如果帕兰提尔的潜在雇员流露出哪怕一丝对首次公开募股和退出策略的兴趣，他或她就得不到这份工作。沙亚姆·桑卡尔是帕兰提尔录用的第十三个人，如今是其首席技术官；他说，这关乎“雇佣兵与传教士”之间的区别——前者关注潜在横财，后者则因帕兰提尔所做的工作而受到吸引。帕兰提尔想要后者，并竭力避免录用前者。

[[P034]] 与其他科技公司相比，帕兰提尔的薪酬并不算高，这有助于筛掉那些雇佣兵。新员工有三种薪酬选择：低现金／高股权、中等现金／中等股权，或高现金／低股权。但“高现金”也并不算高。薪资上限是卡普的薪水，而他的薪水并不高：帕兰提尔成立后的头十年里，他每年只拿约 125,000 美元。即使在 2000 年代中期公司估值达到 200 亿美元时，情况也是如此。“只有当你们赚钱时，我才赚钱，”卡普对同事说过，而且他是认真的。他也喜欢说，自己创办帕兰提尔的目标不是打造世界上最有价值的公司，而是打造世界上最重要的公司。尽管卡普并不忌讳炫耀自己的美国运通黑卡，但除此以外，他不赞成炫富或过度物质主义。他少有的一次动怒，是发现帕兰提尔停车场里停着一辆新的保时捷（它属于一名公司高管）。

[[P035]] 据内森·盖廷斯说，相对较低的薪酬，加上帕兰提尔是一家从事晦涩工作的无名公司，起初令其难以吸引有前途的求职者。“招聘很困难，因为为什么不去 Facebook 或其他如今薪水更高、又能向朋友解释得清楚的公司工作呢？”盖廷斯说。他和其他联合创始人最终得出结论：大学一毕业便加入帕兰提尔的人，最有可能在公司取得成功。对他们而言，钱不是那么大的问题，而且他们通常也更容易适应帕兰提尔独特的文化。

[[P036]] 早年间，卡普、盖廷斯、科恩和朗斯代尔都会面试潜在雇员，而每一份工作邀约都必须由他们四人签字同意。与卡普面试很有挑战性——不是因为他问的问题难，而是因为他几乎不提问，也既无兴趣、亦无能力寒暄。几乎没有人离开房间时会觉得自己面试表现得很出色。恰恰相反：他们会走出去，认定自己拿不到这份工作。但以他奇特的方式，卡普证明自己很擅长判断软件工程师的能力。鲍勃·麦格鲁和阿基·贾恩对他识别技术人才的眼光十分好奇，以至于开始把自己已决定不要的候选人推荐给他，只为看看卡普是否也会否决他们。卡普总能准确无误地嗅出那些不合格者。

[[P037]] 不过，也许卡普最臭名昭著的一场面试，是与一位最终获得职位的人进行的。路易斯·莫斯利毕业于牛津大学，曾希望在英国从政。但他的家族历史使这成为不可能：他的祖父是第二次世界大战期间的英国法西斯领袖奥斯瓦尔德·莫斯利，祖母则是著名的米特福德姐妹之一戴安娜·米特福德，最为人所知的是她与希特勒的密切友谊。一群历史学家曾将奥斯瓦尔德·莫斯利评为二十世纪最糟糕的英国人；虽然路易斯拒绝了祖父母的观点，但他的姓氏成了一项无法克服的负担——保守党内部人士最终明确表示，他们绝不可能提名他参选公职，因为他会因这层关联而受污。

[[P038]] 经朋友介绍，他认识了帕兰提尔；经过几轮面试后，他飞往帕洛阿尔托与卡普会面。莫斯利刚一坐下，卡普就开始背诵奥斯瓦尔德·莫斯利在 1939 年发表的一篇演说，其中要求英国与纳粹德国寻求和平。“我们这一代人不会像老鼠一样死在波兰的洞穴里。他们不会死去，而将活着看到头顶的英格兰天空，感受脚下的英格兰土地，享受美丽的英格兰乡野……”卡普并非只重复几句话；他持续了好几分钟，凭记忆复述那篇演说。莫斯利震惊地沉默坐着。卡普背完后，做了几个太极动作，便没有道别就走出了房间。惊魂未定的莫斯利以为家族的黑暗过去又一次毁掉了他的机会。但并没有：他被录用了，后来负责帕兰提尔在英国的业务。（面试几年后，卡普在伦敦与莫斯利以及一名为帕兰提尔担任顾问的退役英国军官会面。卡普问这名军官是否知道莫斯利的背景。他说自己知道，但补充道：“嗯，我们每个人的衣柜里都有骷髅。”卡普厌恶地看着他。“一具骷髅？”他难以置信地说，“那他妈是哥斯拉在衣柜里。”）

[[P039]] 帕兰提尔从创立之初就有一项政策：不雇用销售人员。朗斯代尔说，他和其他创始人认为，销售团队会对创新产生腐蚀性影响。“当你雇用非常强势的顶级销售人员时，他们会接管文化，”朗斯代尔说。“他们会说：‘是我们带来收入，是我们把食物带回家；为了让我们养活你们，我们需要 X、Y 和 Z。’公司文化会变得极其围绕服务这些顶级销售人员。”帕兰提尔人相信，他们能够开发出真正具有变革性的技术，并希望避免出现迫使产品过快推向市场的情况；不设销售队伍，是确保短期主义不会占上风的一种方式。此外，帕兰提尔已有一位王牌销售员——卡普；他后来证明，自己在说服潜在客户方面与说服同事一样出色。讽刺的是，帕兰提尔没有人比卡普更轻蔑销售人员。他曾说，自己唯一会雇用销售团队的情况，就是“被公交车撞了”。2019 年，也就是帕兰提尔上市前一年，他终于让步；但即使如此，他仍明确表示自己并不看得起销售人员。很难判断，他对销售人员的反感究竟源于一种有充分依据的信念——即他们永远无法像他一样有能力地销售帕兰提尔——还是一种自我厌恶的表现。也许两者皆有。
